# 🔐 Image Encryption Tool

A Python-based image encryption and decryption tool developed as part of my Prodigy Infotech Cyber Security Internship.

## 📌 About the Project

This project demonstrates how an image can be transformed into an encrypted form using pixel-level operations and then restored to its original form through the corresponding decryption process.

The project also includes a simple web interface that allows users to interact with the image encryption system.

## 🚀 Features

- Image encryption
- Image decryption
- Pixel-level image transformation
- Simple web-based interface
- Upload and process images
- Download processed images
- Python-based implementation
- Easy-to-use interface

## 🛠️ Technologies Used

- Python
- Flask
- Pillow (PIL)
- HTML
- CSS
- JavaScript

## ⚙️ How It Works

The input image is read using Python and Pillow. The image data is processed using an encryption operation to transform the pixel values.

The encrypted image can then be decrypted using the corresponding decryption operation to recover the original image.
